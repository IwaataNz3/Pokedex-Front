## Pokédex
Aplicação web para cadastrar e consultar pokémons. O back end é feito em Java e o front end consome a API para cadastrar, listar, buscar e excluir registros.

Tela principal da Pokédex

Funcionalidades Cadastrar pokémon com número, nome, tipo, altura (m), peso (kg) e data da captura Listar todos os pokémons cadastrados Buscar pokémon por código Excluir pokémon, com mensagem de confirmação na tela
